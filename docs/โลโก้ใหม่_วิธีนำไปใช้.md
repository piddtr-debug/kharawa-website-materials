# วิธีนำโลโก้ใหม่ไปใช้ในเว็บไซต์ KHARAWA

## จุดที่ต้องเปลี่ยน

1. โลโก้ใน Header หน้าแรก
2. โลโก้ใน Footer
3. โลโก้หน้า Collection
4. โลโก้ในหน้ารองทั้งหมด
5. favicon หรือ site icon หากระบบรองรับ
6. Open Graph image / social sharing image หากต้องการใช้ภาพนี้แทนภาพเดิม
7. metadata หรือ JSON-LD ที่อ้างอิงรูปโลโก้เดิม

## ไฟล์ที่ใช้

```text
assets/KHARAWA-logo-new.png
```

ภาพนี้เป็นภาพแนวตั้งที่มีพื้นหลังและงานอาร์ตเต็มภาพ ไม่ใช่โลโก้พื้นใสแบบแยกชิ้น ดังนั้นควรใช้ `object-fit: contain` และกำหนดพื้นที่แสดงผลให้เหมาะสม เช่น:

```css
.brand-logo {
  width: 96px;
  height: 56px;
  object-fit: contain;
  object-position: center;
}
```

หากนำไปใช้เป็น favicon ภาพจะถูกย่อมากและรายละเอียดมือ/ข้อความอาจอ่านไม่ชัด ควรทำไฟล์ไอคอนสี่เหลี่ยมแยกภายหลัง
