# สถานะระบบ KHARAWA ณ วันที่ 3 พ.ย. 2026

เอกสารนี้สรุปว่าระบบทั้งหมดทำไปถึงไหนแล้ว อะไรเสร็จ อะไรค้าง อะไรรอเจ้าของร้านทำเอง และอะไรรอข้อมูลจากเจ้าของ เพื่อใช้พัฒนาต่อ

ที่มาของข้อมูล: โค้ดและเอกสารใน repo (branch `main` ณ commit `27b9540`), รายการ Pull Request ใน GitHub และบันทึกจากเธรดงานของโปรเจกต์ (ล่าสุดถึง 3 พ.ย. 2026)

## หมายเหตุเรื่องการตรวจสอบ (อ่านก่อน)

- เครื่องที่ใช้ทำงานเข้า github.io, script.google.com, LINE และ Facebook ไม่ได้ จึง **ยังไม่ได้ตรวจเว็บจริงและระบบหลังบ้านด้วยตัวเองเลย**
- สิ่งที่ระบุว่า "ใช้งานได้" ในเอกสารนี้ มาจากคำยืนยันของเจ้าของร้านในเธรด (เช่น เว็บเปิดได้เมื่อ 2 พ.ย.) หรือจากการทดสอบกับข้อมูลจำลองในเครื่องตอนเขียนโค้ด ไม่ใช่การทดสอบกับระบบจริง
- สิ่งที่ไม่มีหลักฐาน จะเขียนว่า **ยังไม่ได้ตรวจ**
- ไฟล์นี้ไม่มีรหัสลับใด ๆ ห้ามเพิ่ม token, App Secret, รหัสผ่าน หรือ PIN ลงไฟล์นี้

### 2.6 LINE OA (@737yiaxp)

**เสร็จแล้ว**
- `docs/line-broadcast.gs` (PR #12): ส่งข้อความรูป ชื่อ ไซส์ ราคา และปุ่มดูสินค้า ให้ผู้ติดตามเมื่อแถวเป็น "ลงขาย" มีรูป และยังไม่ถูกส่ง จดเวลาลงคอลัมน์ N กันส่งซ้ำ ส่งไม่เกิน 3 ชิ้นต่อรอบ ตรวจทุก 10 นาที ปิดเป็นค่าเริ่มต้น มี `broadcastDryRun` ให้ดูก่อนส่งจริง
- คู่มือไทย `docs/ตั้งค่า_LINE_ส่งสินค้าใหม่อัตโนมัติ.md` และชุดโปสเตอร์ A4 / QR (ไอดีจริง @737yiaxp) ในโฟลเดอร์ไฟล์โปรเจกต์ `line-oa/` พร้อมคู่มือตั้งค่า OA

**ทำค้างอยู่ / รอเจ้าของทำเอง**
- ข้อมูล ณ 3 พ.ย.: เจ้าของวางโค้ดใน Apps Script แล้ว กำลังจะใส่ token ใน Script Properties และรัน `broadcastDryRun`
- ความจำโปรเจกต์ (2 พ.ย.) ระบุว่าเปิดส่งอัตโนมัติและตั้ง trigger ทุก 10 นาทีแล้ว แต่ข้อมูลล่าสุดในเธรด 3 พ.ย. ยังอยู่ขั้นใส่ token และทดลองรัน **สองข้อนี้ขัดกัน จึงยังสรุปไม่ได้ว่าเปิดใช้จริงหรือยัง ต้องถามเจ้าของ**
- ต้องทำเอง: เปิด Messaging API ที่ manager.line.biz, ออก Channel access token ที่ developers.line.biz, วางใน Script Properties (`LINE_CHANNEL_ACCESS_TOKEN`), ตั้ง `LINE_BROADCAST_ENABLED=yes` เมื่อพร้อม, รัน `setupBroadcastTrigger` หนึ่งครั้ง ห้ามส่ง token ในแชทหรือเก็บใน GitHub
- ตรวจโควต้าข้อความฟรีของ OA ก่อนเปิด
- สแกน QR ในโปสเตอร์ด้วยมือถือก่อนพิมพ์ **ยังไม่ได้สแกนทดสอบ**
- ปุ่ม LINE บนเว็บชี้ @737yiaxp ถูกต้องในโค้ด แต่ **ยังไม่ได้ตรวจบนเว็บจริงหลังรีเฟรช**

### 2.7 Facebook

**เสร็จแล้ว**
- ปุ่ม Facebook บนเว็บชี้เพจ KHARAWA (`profile.php?id=61559849011860`) และรวมเข้า `main` แล้ว (PR #17) ตัวเลขนี้น่าจะเป็น Page ID แต่ **ยังไม่ได้ยืนยัน** (จะยืนยันตอนใช้ Graph API Explorer)

- ทดสอบกับข้อมูลจำลองเท่านั้น **ยังไม่ได้ทดสอบกับ Facebook จริง**

**ทำค้างอยู่ / รอเจ้าของทำเอง** (อยู่ในเธรด "แชร์สินค้ามือสองลงโซเชียล")
- เจ้าของมีเพจแล้ว ส่งลิงก์เพจแล้ว ขั้นถัดไปคือ ข้อ 3 วางโค้ด `facebook-post.gs` เป็นไฟล์ใหม่ใน Apps Script (รอเจ้าของบอกว่า "เห็นฟังก์ชันแล้ว")
- ที่เหลือที่ต้องทำเอง: สร้างแอปที่ developers.facebook.com, ใส่ `FB_APP_ID` / `FB_APP_SECRET` / `FB_PAGE_ID` ใน Script Properties, ออกโทเคนชั่วคราวจาก Graph API Explorer แล้วรัน `facebookExchangeToken`, ทดลอง `facebookDryRun`, แล้วค่อยตั้ง `FB_POST_ENABLED=yes` และรัน `setupFacebookTrigger`
- ห้ามส่ง App Secret หรือโทเคนในแชท

## 4. รอข้อมูลจากเจ้าของร้าน (ยังไม่ได้รับ)

- ราคาจริงของสินค้า (ตอนนี้ทั้งเว็บยังแสดง "ราคาจะแจ้งภายหลัง")
- ตารางไซส์
- เงื่อนไขจัดส่งและคืนสินค้า
- ข้อความ PDPA / นโยบายความเป็นส่วนตัว (ข้อความยินยอมในฟอร์มตอนนี้เป็นร่าง)
- เรื่องราวแบรนด์ (หน้า Brand Story)
- รูปคนใส่ (โมเดล) และรูปสินค้าต้นฉบับความละเอียดสูง (สินค้า 3 ชิ้นใน 5 ชิ้นใช้รูปครอปจากภาพแคปเก่า คมน้อย)
- กติกาฝากขาย: ค่าธรรมเนียม ระยะเวลาฝาก วิธีจ่ายเงินให้ผู้ฝาก
- การตัดสินใจเรื่องช่องทางเช็กเอาต์จริง (ตะกร้าตอนนี้เป็นต้นแบบ ยังไม่รับคำสั่งซื้อ) และหน้า `/track`
- ยืนยันว่าจะใช้โดเมนจริงหรือไม่ (มีผลกับ `SITE_URL`, `og:image`)

## 5. สิ่งที่เจ้าของต้องทำเอง (เรียงตามความสำคัญ)

5. สแกน QR โปสเตอร์ LINE ก่อนพิมพ์
6. ตัดสินใจเรื่องหน้าแชท (PR #15) และปิด PR #2 / #3
7. ส่งข้อมูลตามหัวข้อที่ 4

## 6. งานพัฒนาต่อที่เสนอ

1. ปรับ `README.md` ให้ตรงกับระบบปัจจุบัน และตัดสินใจเรื่องโค้ด Supabase ที่ไม่ได้ใช้
