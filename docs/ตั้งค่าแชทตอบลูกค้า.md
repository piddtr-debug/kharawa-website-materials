# ตั้งค่าแชทตอบลูกค้าของร้านเอง

หน้าแชทอยู่ที่ `/admin/chat.html` (เปิดจากปุ่ม "💬 แชทตอบลูกค้า" ในหน้า /admin/) ต้องใช้รหัสผ่านที่คุณตั้งเอง

## ขั้นที่ 1 วางสคริปต์ (ใน Google Sheet เดิม)
1. เปิดชีต > Extensions > Apps Script
2. เปิดไฟล์โค้ดหลัก (consignment) แล้วแทนที่ด้วยเวอร์ชันใหม่จาก `docs/consignment-apps-script.gs` (เพิ่มมาแค่ 2 บรรทัดใน `doPost`)
3. กด + เพิ่มไฟล์ใหม่ ตั้งชื่อ `line-chat` แล้ววางโค้ดจาก `docs/line-chat.gs`
4. กดบันทึก

## ขั้นที่ 2 ตั้งรหัสผ่านแอดมิน
Project Settings (รูปเฟือง) > Script Properties > Add
- `CHAT_ADMIN_PIN` = รหัสผ่านที่คุณตั้งเอง อย่างน้อย 6 ตัว (อย่าส่งให้ใครในแชท)
- `LINE_CHANNEL_ACCESS_TOKEN` มีอยู่แล้วจากตอนทำ broadcast

## ขั้นที่ 3 Deploy ใหม่
Deploy > Manage deployments > ดินสอ > Version: New version > Deploy (URL เดิมใช้ต่อได้)
แล้วเลือกฟังก์ชัน `chatSetup` กด Run หนึ่งครั้ง (ครั้งแรกจะขออนุญาตเพิ่ม เพราะต้องใช้ Drive เก็บรูปที่ลูกค้าส่งมา)

## ขั้นที่ 4 ต่อ LINE เข้ากับสคริปต์
LINE Developers Console > Channel ของร้าน > Messaging API
- Webhook URL = URL ของสคริปต์ที่ลงท้าย `/exec`
- กด Verify แล้วเปิด Use webhook
- ที่ LINE Official Account Manager > ตั้งค่าตอบกลับ ปิด "ข้อความตอบกลับอัตโนมัติ" ถ้าไม่ต้องการให้ซ้ำกับของไลน์

## ข้อควรรู้
- ข้อความที่ร้านส่งผ่านหน้านี้ใช้ Push message นับโควตาข้อความของ LINE OA (แพ็กเกจฟรีมีจำกัดต่อเดือน) ดูโควตาที่ LINE OA Manager
- ข้อความที่ตอบจากแอป LINE OA Manager จะไม่แสดงในหน้านี้
- สคริปต์ Apps Script อ่านลายเซ็นของ LINE ไม่ได้ จึงตรวจว่าข้อความมาจาก LINE จริงไม่ได้ เก็บเป็นข้อความธรรมดาเท่านั้น
- ใส่รหัสผิด 10 ครั้งจะถูกล็อก 10 นาที
- ปุ่มข้อความสำเร็จรูปแก้ได้ที่ปุ่ม "✎ แก้ไข" ในหน้าแชท (เก็บในเบราว์เซอร์เครื่องนั้น) ใส่ `{ชื่อ}` เพื่อแทนชื่อลูกค้า
