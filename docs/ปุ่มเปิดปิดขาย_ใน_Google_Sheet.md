# ปุ่มเปิด/ปิดขาย ใน Google Sheet

## วิธีติดตั้ง (ทำครั้งเดียว)
1. เปิด Google Sheet "KHARAWA ฝากขาย"
2. เมนูบน: **ส่วนขยาย → Apps Script**
3. กดเครื่องหมาย **+** ข้าง "ไฟล์" → เลือก **สคริปต์** → ตั้งชื่อ `admin-menu`
4. คัดลอกโค้ดจากไฟล์ `docs/admin-menu.gs` ไปวาง แล้วกด **บันทึก** (รูปแผ่นดิสก์)
5. เลือกฟังก์ชัน `onOpen` ด้านบน แล้วกด **เรียกใช้** → กด "อนุญาต" ตามที่ Google ถาม
6. กลับไปที่ชีต แล้วรีเฟรชหน้า จะเห็นเมนู **🛍️ KHARAWA** ที่แถบด้านบน

## วิธีใช้ทุกวัน
1. เปิดแท็บ **ฝากขาย**
2. คลิกแถวสินค้า (หรือลากเลือกหลายแถว)
3. เมนู **🛍️ KHARAWA** แล้วเลือก:
   - ✅ ลงขาย = แสดงบนเว็บ
   - 🔒 จองแล้ว / 💰 ขายแล้ว = แสดงบนเว็บพร้อมป้ายสถานะ
   - 🚫 ซ่อน = ไม่แสดงบนเว็บ
