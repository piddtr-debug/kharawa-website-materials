# ส่งสินค้ามือสองชิ้นใหม่เข้า LINE OA อัตโนมัติ

เมื่อคุณเปลี่ยนสถานะแถวในชีตเป็น "ลงขาย" ระบบจะส่งข้อความ 1 ข้อความ (รูป + ชื่อ + ราคา + ปุ่ม "ดูสินค้า") ให้ทุกคนที่ติดตาม LINE OA @737yiaxp แล้วจดเวลาลงคอลัมน์ N กันส่งซ้ำ

**ปิดอยู่เป็นค่าเริ่มต้น** จะไม่ส่งอะไรจนกว่าคุณจะตั้ง `LINE_BROADCAST_ENABLED = yes` เอง

> ห้ามส่งหรือวางโทเคนในแชต ในโค้ด หรือใน GitHub เด็ดขาด ใครมีโทเคนส่งข้อความในนามร้านได้ ให้วางในช่อง Script Properties ของ Apps Script เท่านั้น (ขั้นที่ 3) ถ้าเผลอเปิดเผย ให้กด Reissue ในขั้นที่ 2 เพื่อออกอันใหม่

## ขั้นที่ 1: เปิด Messaging API ของ LINE OA
1. เข้า https://manager.line.biz เลือกบัญชี @737yiaxp
2. เมนู **การตั้งค่า (Settings)** → **Messaging API** → กด **เปิดใช้ Messaging API (Enable Messaging API)** แล้วเลือก/สร้าง Provider ตามที่หน้าจอบอก

## ขั้นที่ 2: ออก Channel access token
1. เข้า https://developers.line.biz/console เลือก Provider → เลือกช่อง Messaging API ของ @737yiaxp
2. แท็บ **Messaging API** เลื่อนลงไปหัวข้อ **Channel access token (long-lived)** → กด **Issue**
3. กดคัดลอกโทเคน (ยาวมาก) เก็บไว้ในคลิปบอร์ด อย่าส่งให้ใคร

## ขั้นที่ 3: วางโทเคนใน Apps Script (ทำเองคนเดียว)
1. เปิด Google Sheet ฝากขาย → **ส่วนขยาย (Extensions)** → **Apps Script**
2. ซ้ายมือกด **+** ข้าง "Files" → **Script** → ตั้งชื่อ `line-broadcast` แล้ววางโค้ดจากไฟล์ `docs/line-broadcast.gs` ทั้งหมด → กดบันทึก (รูปแผ่นดิสก์)
3. ซ้ายมือกดรูปเฟือง **Project Settings** → เลื่อนลงหัวข้อ **Script Properties** → **Add script property**
   - ชื่อ `LINE_CHANNEL_ACCESS_TOKEN` ค่า = วางโทเคน
   - ชื่อ `LINE_BROADCAST_ENABLED` ค่า = `no` (ยังไม่เปิดก่อน)
   → กด **Save script properties**

## ขั้นที่ 4: ทดลองโดยยังไม่ส่งจริง
1. กลับหน้าโค้ด เลือกฟังก์ชัน `broadcastDryRun` ในแถบด้านบน → กด **Run** (อนุญาตสิทธิ์ครั้งแรก)
2. เปิด **Execution log** ดูข้อความที่ "จะส่ง" ถ้าไม่มีอะไรขึ้น แปลว่าไม่มีแถวที่สถานะ "ลงขาย" + มีรูป + ยังไม่ถูกส่ง

## ขั้นที่ 5: เปิดใช้งานจริง (เมื่อพร้อม)
1. ใน Script Properties แก้ `LINE_BROADCAST_ENABLED` เป็น `yes`
2. เลือกฟังก์ชัน `setupBroadcastTrigger` → **Run** หนึ่งครั้ง (จะตั้งให้ตรวจทุก 10 นาที)
3. ต้องการหยุด: แก้ `LINE_BROADCAST_ENABLED` เป็น `no` หรือลบ Trigger ที่เมนูนาฬิกาด้านซ้าย

## ที่ควรรู้
- ข้อความ broadcast นับเป็นโควต้าข้อความของ LINE OA ตามจำนวนผู้ติดตาม แผนฟรีมีจำกัดต่อเดือน เช็คโควต้าที่ LINE OA Manager ก่อนเปิด
- ส่งได้สูงสุด 3 ชิ้นต่อรอบ เพื่อกันส่งรัวถ้าเปลี่ยนสถานะหลายแถวพร้อมกัน
- ถ้า LINE ตอบผิดพลาด (เช่น โทเคนผิด โควต้าเต็ม) ระบบจะหยุดและลองใหม่รอบถัดไป ดูสาเหตุได้ที่ Executions ใน Apps Script
- ต้องเก็บรูปแบบ "ลงขาย" ให้ตรงตามตัวเลือกในช่องสถานะของชีต
