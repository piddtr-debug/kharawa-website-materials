เว็บไซต์ที่ตรวจพบปัจจุบัน: https://kharawa-8jhdxqn6.manus.space/

## ไฟล์

- `assets/KHARAWA-logo-new.png` — ต้นฉบับโลโก้ใหม่ที่ผู้ใช้ส่งมา ขนาด 1228×1281 px (เก็บไว้เป็น master ไม่ใช้บนเว็บโดยตรง)
- `docs/โลโก้ใหม่_วิธีนำไปใช้.md` — จุดที่ต้องเปลี่ยนในเว็บไซต์
- `site/index.html` — Landing Page หลักแบบ Static
- `site/styles.css` — ระบบสี, layout และ responsive design
- `site/script.js` — เมนูมือถือและ interaction เบื้องต้น
- Product Showcase พร้อมหน้าต่างรายละเอียดสินค้า
- Cart Drawer เพิ่ม/ลด/ลบสินค้าและบันทึกตะกร้าด้วย `localStorage`
- Language switcher `TH / EN` สำหรับเมนู ปุ่ม หัวข้อ สินค้า Product Modal, Cart และ Footer พร้อมจำค่าภาษาที่เลือก
- Pre-loved Consignment form สำหรับฝากขายสินค้ามือสอง พร้อมข้อมูลสินค้า สภาพ ราคา ช่องทางติดต่อ รายละเอียด และรูปภาพ
- `site/assets/` — ไฟล์ภาพที่เว็บใช้จริง ตัดมาจากต้นฉบับโลโก้

### ไฟล์ใน `site/assets/`

ต้นฉบับโลโก้เป็นภาพแคปหน้าเว็บ มีแถบเทาขอบบน/ล่าง เมนู และข้อความ "FIELD EDITION 001" ติดอยู่ในภาพ จึงครอปออกก่อนนำมาใช้

| ไฟล์ | ใช้ที่ |
| --- | --- |
| `kharawa-art.webp` | ภาพ Hero (ครอปเป็น 1228×1060 ไม่มีเมนู/ป้ายติดมา) |
| `icon-192.png`, `icon-512.png` | โลโก้สี่เหลี่ยมใน Header, Footer และส่วน Contact |
| `favicon-32.png`, `apple-touch-icon.png` | favicon และไอคอนหน้าจอโฮมมือถือ |
| `og-image.jpg` | ภาพแชร์โซเชียล 1200×630 (ยังไม่ได้ใส่ใน `<meta>` ดูด้านล่าง) |
| `plates/plate-1…5.webp` | ภาพสินค้าชั่วคราว 4:5 (ดูหัวข้อ "ภาพสินค้าชั่วคราว") |

> `og:image` ต้องใช้ URL เต็ม (absolute) จึงยังไม่ได้เพิ่มแท็กใน `index.html` เมื่อรู้โดเมนจริงให้เพิ่ม
> `<meta property="og:image" content="https://<โดเมน>/assets/og-image.jpg" />`

เนื่องจาก workflow ปล่อยเฉพาะโฟลเดอร์ `site/` ไฟล์ภาพทุกไฟล์ที่เว็บอ้างอิงต้องอยู่ใน `site/` เท่านั้น (อย่าอ้าง `../assets/...`)

### ดีไซน์ v2 (หรูหรา แต่ยังเป็นภาษาของ Manus)

โครงหน้าเหมือนเดิมทุกส่วน (Hero → แนวคิด → คอลเลกชัน → ฝากขาย → ติดต่อ) ปรับเฉพาะสัดส่วน ตัวอักษร และรายละเอียด

- **ฟอนต์** (ลิงก์ Google Fonts ใน `<head>` ของ `index.html`): Archivo สำหรับตัวอักษรอังกฤษ (ใช้แกนความกว้าง `font-stretch` ให้หัวข้อดูกว้างและหนา) และ Noto Sans Thai สำหรับภาษาไทยทั้งหมด
- **สี** (ตัวแปรใน `:root` ของ `styles.css`): ดำ `#11100e`, ครีม `#f2e7d3`, แดง `#c9231c`, น้ำเงิน `#164f9b` เหมือน Manus ส่วนตัวอักษรเล็กสีแดงบนพื้นดำใช้ `--red-hi: #e8604f` เพราะแดงแบรนด์บนพื้นดำมี contrast แค่ 3.4:1 (ต้อง 4.5:1)
- **กริด** 12 คอลัมน์ กว้างสุด 1360px ขอบข้างและระยะห่างระหว่างส่วนเป็นตัวแปร (`--pad`, `--section-y`) ทุกส่วนมีเส้นบางและเลขลำดับ (01–04) เหมือนสไตล์ Manus
- **ภาษาไทย**: ไม่ใช้ตัวอักษรเว้นระยะหรือตัวพิมพ์ใหญ่กับข้อความไทย (ตัวแปร `--track-label` และ `--track-display` เปลี่ยนเป็นค่าเกือบ 0 เมื่อ `html[lang="th"]`) ระยะบรรทัดไม่ต่ำกว่า 1.15 ที่หัวข้อและ 1.95 ที่ย่อหน้า คำอังกฤษที่แทรกในประโยคไทยใช้ Archivo
- **คำไทย**: ใช้ "ตะกร้า" แทน "ถุง", "สั่งจองล่วงหน้า" แทน Pre-order, "ราคาจะแจ้งภายหลัง" แทน PRICE TBC ข้อความทั้งหมดอยู่ที่ `TRANSLATIONS` ใน `script.js` และข้อความตั้งต้นใน `index.html` ต้องตรงกับ `TRANSLATIONS.th` (ใช้เมื่อ JavaScript ไม่ทำงาน)
- ตะกร้า หน้าต่างสินค้า สลับภาษา และฟอร์มฝากขายของ Manus ยังทำงานเหมือนเดิม ปรับเพิ่มเฉพาะ: ใช้ `localStorage` แบบป้องกันการถูกบล็อก, สถานะในหน้าต่างสินค้าแปลตามภาษา, ฟอร์มฝากขายแจ้งตามจริงว่ายังไม่ได้ส่งถึงทีมงาน

### ภาพสินค้าชั่วคราว (plates)

`site/assets/plates/plate-1.webp` ถึง `plate-5.webp` (สัดส่วน 4:5) เป็นภาพประกอบแนวคิดของเสื้อ 4 แบบและหมวก 1 แบบ วาดจากงานศิลป์ของแบรนด์ ไม่ใช่ภาพถ่ายสินค้าจริง ใช้ในการ์ด หน้าต่างรายละเอียด และตะกร้า (กำหนดด้วยคลาส `.product-image-1` ถึง `-5` ใน `styles.css`)

เมื่อมีรูปสินค้าจริง วางไฟล์ใน `site/assets/products/` (แนะนำ WebP สัดส่วน 4:5) แล้วเพิ่ม `<img>` ในการ์ดนั้นของ `site/index.html`:

```html
<div class="product-image product-image-1 has-photo">
  <span>KH / FS-01</span>
  <img src="./assets/products/fs-01.webp" alt="เสื้อ First Press Tee ด้านหน้า" width="800" height="1000" loading="lazy" />
</div>
```

รูปจะเติมเต็มกรอบและทับภาพชั่วคราว ป้ายรหัสสินค้า (`KH / FS-01`) ยังอยู่มุมซ้ายบน ถ้าจะให้หน้าต่างรายละเอียดและตะกร้าใช้รูปจริงด้วย ให้เปลี่ยนค่า `--plate` ของคลาส `.product-image-1` ใน `styles.css` เป็นไฟล์รูปจริง

## ขอบเขตสำคัญ

Repository นี้ยัง **ไม่ใช่ source code เต็มของเว็บไซต์ที่เผยแพร่** เนื่องจาก source code ต้นฉบับยังไม่ได้ถูกส่งเข้ามาใน Sandbox ขณะจัดทำ repository

ชุดนี้เป็น Landing Page แบบ Static สำหรับนำไปพัฒนาต่อ ยังไม่มี database, authentication หรือระบบ order จริง ดังนั้นไม่ควรนำส่วน `/track` และ `/admin/pre-orders` ไปใช้งาน production โดยตรง

ตะกร้าสินค้าในเวอร์ชันนี้เป็น client-side prototype: สินค้ายังมีสถานะ `PRE-LAUNCH` และ `PRICE TBC` จึงยังไม่เปิด checkout จริง ปุ่ม `REQUEST PRE-ORDER` จะเปิดใช้งานเมื่อเชื่อมราคาจริง ฐานข้อมูล และระบบรับคำสั่งซื้อแล้ว

ฟอร์มฝากขายในเวอร์ชันนี้เป็น draft form: หลังส่งข้อมูลจะเก็บเฉพาะข้อมูลแบบร่างไว้ใน `localStorage` ของ Browser เครื่องนั้น ยังไม่ได้ส่งเข้าอีเมล, LINE, database หรือระบบหลังบ้านจริง จึงต้องเชื่อม submission endpoint ก่อนใช้งานรับฝากขายจริง

## เมื่อมี source code

เปลี่ยนการอ้างอิงโลโก้เดิมทุกจุดไปใช้ไฟล์ใน `site/assets/` (ไม่ใช้ `KHARAWA-logo-new.png` ตรงๆ)

และตรวจอย่างน้อยที่ Header, Footer, Collection, favicon, Open Graph image และ JSON-LD/metadata หากมี
